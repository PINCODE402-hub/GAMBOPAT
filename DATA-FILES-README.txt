Edit these simple files to update the website (no coding needed).

banner.json        -> set "enabled": true and change "text" to show a promo bar on every page.
testimonials.json  -> add real reviews, e.g.
  [{"name": "Kwame A.", "text": "Great gate, delivered on time!", "stars": 5}]
  Leave [] and the section stays hidden.
prices.json        -> add starting prices, e.g.
  [{"item": "Main gate (swing)", "from": "GHS 0", "note": "Per size/design"}]
  Leave [] and the price guide stays hidden.
